# 好運選號 Lucky Number Picker

一款為台灣彩券設計的隨機選號工具，支援威力彩、大樂透與今彩 539。

使用者可以調整產生組數、鎖定或排除偏好號碼，並收藏或複製喜歡的號碼組合。所有偏好與收藏都保存在使用者自己的裝置中，不會上傳至伺服器。

## 線上體驗

https://dawn-hsu.github.io/lucky-number-picker/

## 主要功能

- 支援威力彩、大樂透與今彩 539
- 一次產生最多 10 組號碼
- 鎖定希望每組出現的號碼
- 排除不希望出現的號碼
- 收藏喜歡的號碼組合
- 一鍵複製選號結果
- 收藏與偏好保存在本機裝置
- 支援桌機與手機版面

## 使用技術

- HTML
- CSS
- JavaScript
- Local Storage
- GitHub Pages

## 使用方式

1. 選擇彩券種類。
2. 調整想產生的組數。
3. 視需要設定鎖定或排除號碼。
4. 點擊「替我選號」產生結果。
5. 收藏或複製喜歡的號碼組合。

## 注意事項

本工具僅供隨機選號與娛樂使用，與台灣彩券無關，也無法提高中獎機率。未滿 18 歲不得購買或兌領彩券，請理性投注。
